PLAYBOOK: RESEARCH (reads a book once, builds its notes and Idea Bank)
Inputs: the job (bookId, request), the books/<bookId> doc (title, author, code, filePath, fileName).
1. Get the file: Worker API file-url {path: filePath}, then download the 10-minute link. If there is no filePath, fail the job with error "no book file uploaded". While you read, write jobs/<id> {progress:{step, of, label:"Reading chapter N of M"}} (merge, runId) after each chapter.
2. Extract text locally (PDF: `pdftotext -layout`, page by page so you keep page numbers; EPUB: unzip and strip the XHTML in spine order, numbering sections instead of pages). Work only in your scratch directory.
3. Chapter notes: split by chapter. If the Agent tool is available, give chapters to parallel sub-agents (model "sonnet") with this brief: "Return JSON {chapter, pages, keyIdeas:[{idea, mechanism, pages}], stories:[{who, what, pages}], claimsToCheck:[{claim, pages}], lines:[{text (max 25 words), page}]}". Otherwise do it yourself. Save each as booknotes/<bookId>-<NN> = {bookId, chapterNo, title, pages, keyIdeas, stories, claimsToCheck, lines, createdAt}.
4. If the request says "notes only", stop here: update the book (notesCount, researchedAt, digest = 150-250 words on what the book argues and where its strongest material is) and finish.
5. Idea Bank: pick 15-25 ideas. For each, fill the same schema the existing ideas use: {code, bookId, rank, hook, quietPart, why, fromBook, tryThis, evidence (SUPPORTED|MIXED|MYTH|STORY|PHILOSOPHY|CHECK), evidenceNote, sources:[{title,url}], visual, pages, scores:{hook,visual,truth,send} 1-5, total, format, status:"Idea", updatedAt, history:[{status:"Idea", at}]}. Codes: <book code>-NN (book code = books doc "code", else 2-3 uppercase letters from the title; never reuse an existing code prefix).
6. Fact-check: web-search the 5-8 claims that carry the most weight; open the pages you cite; set evidence + evidenceNote from what you found. Health/diet ideas: flag, no numbers. Mark anything unverified as CHECK.
7. Rank by total score; save ideas (batch writes, max 50 per batch). New ideas and booknotes are inserts: never overwrite an existing idea code or note (the API refuses it). Update the book (merge): status "Idea bank ready", digest, notesCount, researchedAt, updatedAt. Summary in runs: counts, top 3 ideas, notable myths.
